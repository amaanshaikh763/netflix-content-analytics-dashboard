# 🎬 Netflix Content Analytics & Business Intelligence Dashboard

## 📖 Project Overview

This project analyzes Netflix's global content catalog using PostgreSQL and Business Intelligence techniques.

The objective is to transform raw Netflix data into meaningful business insights through data profiling, cleaning, exploratory analysis, advanced SQL, and dashboard-ready datasets.

The project follows a real-world analytics workflow similar to what Data Analysts perform in industry, beginning with database creation and ending with executive-level KPI preparation for Power BI visualization.

## 🎯 Business Problem

Netflix offers thousands of Movies and TV Shows across different countries, genres, ratings, and release years.

Understanding how the content library has evolved can help answer important business questions such as:

- Which countries contribute the most content?
- How has Netflix's content library grown over time?
- What percentage of the catalog consists of Movies versus TV Shows?
- Which directors contribute the highest number of titles?
- Which content ratings dominate the platform?

The answers to these questions help support strategic decisions related to content investment, licensing, and audience engagement.

## 🚀 Project Objectives

- Import and manage Netflix data using PostgreSQL
- Perform data profiling and quality assessment
- Clean and validate the dataset
- Explore trends using SQL
- Solve business-driven analytical questions
- Apply advanced SQL concepts including:
  - CTEs
  - Window Functions
  - Ranking Functions
  - Running Totals
  - Percentage Analysis
- Prepare dashboard-ready KPI datasets
- Build a Business Intelligence dashboard using Power BI
